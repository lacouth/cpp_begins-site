    Lista 05 · Algoritmos clássicos: escrevendo na mão¶

    Exercícios da Semana 5 — Algoritmos clássicos: escrevendo na mão.

    Esta lista tem uma regra que vale para todos os exercícios: não use <algorithm>. Nada de std::sort, std::find, std::count_if, std::max_element ou std::accumulate. Tudo aqui se resolve com for, if e uma variável auxiliar.

    Não é birra: cada uma dessas funções existe e é melhor que a sua versão. Você vai usá-las a partir da Lista 08, depois da Avaliação 1. O ponto desta lista é você saber o que elas fazem por dentro antes de passar a chamá-las.

    Como resolver

    Copie o bloco de código de cada exercício, cole no seu compilador online, preencha a parte marcada como ESCREVA SUA SOLUCAO AQUI e rode. A saída mostra quais testes passaram.

    ex06¶

    Escreva busca_binaria, que recebe um std::vector<int> já ordenado e um alvo, e devolve o índice do alvo como std::optional<int> — ou std::nullopt se ele não estiver lá.

    A cada volta, descarte metade dos candidatos: olhe o elemento do meio e decida em qual metade continuar. Compare com o ex01: num vector de mil elementos, a busca linear faz até mil comparações; esta faz no máximo dez.

    Atenção à condição de parada: com inicio < fim em vez de inicio <= fim, a função erra quando sobra um único candidato — e há um caso de teste exatamente para isso.

    busca_binaria({1, 3, 5, 7, 9}, 7)   // -> 3
busca_binaria({1, 3, 5, 7, 9}, 4)   // -> std::nullopt

    // ex06 — versao de arquivo unico (gerada automaticamente,
// nao edite este arquivo direto: edite os fontes em exercicios/ e rode
// tools/gerar_single.py --todos de novo).
//
// Cole este arquivo inteiro no seu compilador online e rode.

#include <cassert>
#include <iostream>
#include <vector>
#include <optional>

// ============================================================
// Declaracoes do exercicio
// ============================================================
#ifndef EX06_H
#define EX06_H

// Retorna o indice de alvo em v usando busca binaria.
// Assume que v esta ORDENADO em ordem crescente.
std::optional<int> busca_binaria(const std::vector<int>& v, int alvo);

#endif

// ============================================================
// ESCREVA SUA SOLUCAO AQUI
// ============================================================
std::optional<int> busca_binaria(const std::vector<int>& v, int alvo) {
    // TODO: mantenha dois indices, inicio e fim. Enquanto inicio <= fim,
    // olhe o elemento do meio: se for o alvo, devolva o indice; se for
    // menor que o alvo, o alvo so pode estar na metade de cima; senao,
    // na de baixo.
    return std::nullopt;
}

// ============================================================
// NAO ALTERE — testes
// ============================================================
int main() {
    std::vector<int> v = {1, 3, 5, 7, 9};

    assert(busca_binaria(v, 1).value() == 0);
    assert(busca_binaria(v, 5).value() == 2);
    assert(busca_binaria(v, 9).value() == 4);

    assert(!(busca_binaria(v, 4).has_value()));
    assert(!(busca_binaria(v, 0).has_value()));
    assert(!(busca_binaria(v, 10).has_value()));

    // um elemento so: o <= da condicao de parada e o que faz isto passar
    std::vector<int> um = {42};
    assert(busca_binaria(um, 42).value() == 0);
    assert(!(busca_binaria(um, 1).has_value()));

    std::vector<int> vazio;
    assert(!(busca_binaria(vazio, 1).has_value()));

    std::cout << "Todos os testes passaram!\n";
    return 0;
}

    ex07¶

    Escreva mediana, que devolve o valor central de um conjunto de números. Se a quantidade de elementos for par, a mediana é a média dos dois centrais.

    Repare na assinatura: o vector vem por valor, e não por const& como no resto do curso. É proposital — a função precisa ordenar, e ordenar o vector de quem chamou seria um efeito colateral surpreendente. Há um caso de teste que verifica exatamente isso.

    Divida por 2.0, e não por 2: com {1, 2}, a mediana é 1.5.

    mediana({3, 1, 2})      // -> 2.0
mediana({4, 1, 3, 2})   // -> 2.5
mediana({})             // -> 0.0

#endif
